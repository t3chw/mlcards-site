# Assets Directory

Please add the following image files to this directory before deploying:

## Required Images:

1. **logo.png** - Your MLCards logo
   - Recommended size: 512x512px or higher
   - Format: PNG with transparency
   - Used in: Header and favicon

2. **preview.png** - Social media preview image
   - Recommended size: 1200x630px (Open Graph standard)
   - Format: PNG or JPG
   - Used in: Social media shares (Twitter, LinkedIn, Facebook)
   - Should showcase your app interface or key features

## Tips:
- Compress images before uploading to keep the site fast
- Consider using WebP format for better performance
- Make sure images are optimized for web use
